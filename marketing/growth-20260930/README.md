## 1. Next steps (internal links)
Jev chose, for every page, one topical next page and one sales-step page from the hub
pages in `next-step-targets.json` (`experiments/jev-site-review/next-steps.mjs` →
`next-steps.json`; a few manual overrides point to the new data pages, listed in
`edits/30-growth-next-steps.json` → `overrides`). The shared footer renders a "Next steps"
block (two Jev picks plus "Request a free catalog review"); the build copies the
rendered block into each page's prerendered HTML so crawlers see the links.

## 2. Music Catalog Deal Tracker
`/data/music-catalog-deals/`: 52 publicly reported deals (2019–2026) and 11 multiples
stated by named companies or valuers, each linked to its source (`data/deals.json`,
`data/multiples.json`). Prices appear only when disclosed or reported; SPACE does not
estimate. Some Billboard/Variety rows rely on search-result text because of paywalls:
spot-check before promoting the page to journalists.

Deal watch: `node experiments/jev-deal-watch/watch.mjs` reads MBW, Digital Music News,
Music Ally, Variety and Billboard RSS; Jev queues likely acquisitions in
`data/deal-queue.json` (status "needs review"). A person verifies each item, adds it to
`data/deals.json`, then runs `node scripts/build-growth-pages.mjs` and the normal build.
Nothing is published automatically.

## 3. Publish gate
`node scripts/jev-publish-gate.mjs CANDIDATE_DIR` checks every sentence that is new
compared with production (production dir is read from marketing/RELEASE.md) for invented
promises, unsourced figures, SPACE policy conflicts and invented credentials. It exits 1
on any flag unless the sentence is fixed or listed with a reason in
`marketing/jev-gate-allowlist.json` after human review. Run it before every deploy.

## 6. AI answers
`experiments/jev-site-review/ai-answers.mjs` asks Jev whether each page opening answers
its H1 in one quotable sentence (`ai-answers.json`). The weakest high-impression pages
get an answer-first opening (`edits/33-growth-ai-answers.json`), using only facts already
on the page with sources.
